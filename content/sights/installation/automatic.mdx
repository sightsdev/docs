### One Line
```bash 
curl -fsSL https://github.com/sightsdev/sights/install.sh | bash
```

<Callout type="warn" title="Warning">
    Curling straight into bash <b>can be risky</b>.<br/>
    <b>You</b> are responsible for any code you execute on your computer.<br/>
</Callout>

### Multi Line
1. Download the script
```bash
curl -fsSL https://github.com/sightsdev/sights/install.sh
```

2. Verify the file is correct
```bash
less install.sh
```

3. Execute
```bash
bash install.sh
```
